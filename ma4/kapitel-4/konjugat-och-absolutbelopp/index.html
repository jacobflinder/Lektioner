02 · Konjugering som spegling

Vad händer med imaginärdelen?

Samma skala på real- och imaginäraxeln. Pilarna går från origo till respektive punkt.

Förutsäg → rita → visaStarta med z = 2 − 3i. Rita först punkten för z̄ själv. Vilken koordinat ändras vid spegling i realaxeln?

a, b ∈ ℝ

z = a + bi

⇒ z̄ = a − bi

(a; b) ⇒ (a; −b)

Realdelen a är oförändrad. Imaginärdelen b byter tecken. Om b = 0 är talet reellt och sitt eget konjugat.

03 · Absolutbelopp · ett avstånd

Hur långt från origo?

z = a + bi

⇒ |z| = √(a² + b²)

Absolutbeloppet är avståndet från origo till punkten (a,b), eller längden av dess positionsvektor. Det är alltid ett icke-negativt reellt tal.

Enskilt → par

z = −3 + 4i

Bestäm |z| och |z̄|. Varför blir de lika trots att imaginärdelens tecken ändras?

|z| = √((−3)² + 4²) = √25 = 5

|z̄| = √((−3)² + (−4)²) = √25 = 5

Speglingen bevarar avståndet till origo. Tecknet på b spelar ingen roll när b kvadreras.

04 · Varför blir produkten reell?

Konjugatet tar bort imaginärdelen i produkten

z = a + bi

z̄ = a − bi

Förutsäg – skriv – kontrolleraVilket uttryck får vi när vi multiplicerar z med z̄? Visa nästa steg först efter ett eget försök.
Nästa beslut:
1 · Använd distributiva lagen

z z̄ = (a + bi)(a − bi)

= a·a + a(−bi) + (bi)a + (bi)(−bi)

= a² − abi + abi − b²i²

2 · Samla likartade termer

z z̄ = a² − b²i²

De blandade imaginära termerna −abi och +abi tar ut varandra.

3 · Använd i² = −1

z z̄ = a² − b²(−1)

= a² + b²

Produkten är ett icke-negativt reellt tal.

4 · Koppla till absolutbeloppet

|z| = √(a² + b²)

|z|² = (√(a² + b²))²

= a² + b² = z z̄

Det gäller också för z = 0, när båda leden är noll.

Kom ihåg: Konjugering är en spegling i realaxeln. Absolutbelopp är ett avstånd. Produkten z z̄ ger avståndets kvadrat.

05 · Begreppskontroll

Vilka tal är reella och icke-negativa?

z = −3 + 4i

Vad är |z|?

Säg varförVad är Im(z)? Vad är z̄? Vilket av dessa tre begrepp representerar ett avstånd?

Im(z) = 4

z̄ = −3 − 4i

|z| = 5

z z̄ = (−3 + 4i)(−3 − 4i) = 9 + 16 = 25 = |z|²

08 · Individuell utcheckning

Kan du använda konjugatet?

3 minuter, utan hjälp

z = −2 − 3i

1. Beräkna z̄.

2. Beräkna |z|.

3. Visa att z z̄ = |z|².

z̄ = −2 + 3i

|z| = √13

z z̄ = (−2 − 3i)(−2 + 3i) = 4 + 9 = 13
