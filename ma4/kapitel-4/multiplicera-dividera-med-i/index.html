4.2 Komplexa tal i polär form · Samma längd, en rotation på 90°

Enskilt → par · skriv först

z = 2 + i

Beräkna iz med i² = −1. Rita z och iz i samma talplan. Vad förändras? Vad är oförändrat?

iz = i(2 + i)

= 2i + i² = −1 + 2i

Punkten flyttas från (2, 1) till (−1, 2): en rotation 90° moturs. Längden är densamma, nämligen √(2² + 1²) = √5.

02 · Rotationsregler · förutsäg → visa

Två rotationer – samma längd

Multiplicera med i

|iz| = |z|

arg(iz) = arg(z) + π/2

90° moturs, positiv rotationsriktning.

Dividera med i

|z/i| = |z|

arg(z/i) = arg(z) − π/2

90° medurs, negativ rotationsriktning.

Argumentreglerna gäller för z ≠ 0 och anger möjliga argument; hela varv kan läggas till eller dras ifrån. Längden bevaras även för z = 0.

Alla tre starttalen har samma absolutbelopp √5. Axlarna har samma längdskala. Byter du tal återställs figuren.

03 · Varför gäller rotationsreglerna?

Förklara rotationsreglerna med algebra

z = a + bi

a, b ∈ ℝ

Förutsäg → skriv → visaVarje klick avslöjar ett matematiskt beslut. Försök skriva nästa rad innan du visar den.
Nästa fråga:
1 · Multiplicera med i

iz = i(a + bi)

= ia + i(bi)

= ai + bi²

= ai + b(−1)

= −b + ai

2 · Tolka koordinatförändringen

(a, b) → (−b, a)

En rotation på 90° moturs, alltså ett argument som ökar med π/2 radianer. Kontrollera gärna med z = 2 + i från starten.

3 · Dividera med i

i(−i) = −i²

= −(−1) = 1

1/i = (1 · (−i))/(i(−i))

= (−i)/1 = −i

z/i = (a + bi)(−i)

= −ai − bi²

= −ai − b(−1)

= b − ai

4 · Tolka divisionens rotation

(a, b) → (b, −a)

En rotation på 90° medurs, alltså ett argument som minskar med 90° (eller π/2 radianer). För z = 0 finns ingen definierad riktning.

5 · Bevisa att längden bevaras

|z| = √(a² + b²)

|iz| = √((−b)² + a²)

= √(b² + a²)

= √(a² + b²)

|z/i| = √(b² + (−a)²)

= √(b² + a²)

= √(a² + b²)

Alla tre absolutbelopp är lika. För z = 0 blir resultatet fortfarande 0; argumentet är då inte definierat.

04 · Självständig tillämpning

Nu bestämmer du både tal och riktning

Enskilt → par → kontroll

z = −3 + 2i

Beräkna iz och z/i och markera alla tre punkterna i talplanet. Beräkna |z| och kontrollera att absolutbeloppet bevaras. Vilken av rotationerna är medurs?

iz = i(−3 + 2i) = −3i + 2i² = −2 − 3i

z/i = −i(−3 + 2i) = 3i − 2i² = 2 + 3i

|z| = √(9 + 4) = √13

|iz| = √(4 + 9) = √13 = |z/i|

Division med i är den medurs rotationen. Kontrollera att alla tre punkterna ligger lika långt från origo.

Multiplicera med i

i² = −1

iz = −b + ai

För z = a + bi blir koordinaterna (−b; a): ett kvarts varv, 90° moturs, runt origo.

Dividera med i

1/i = −i

z/i = −iz

= b − ai

arg(z/i) = arg(z) − π/2

För z = a + bi blir koordinaterna (b; −a): ett kvarts varv, 90° medurs, runt origo.

Längden bevaras

|z| = √(a² + b²)

Efter båda rotationerna är kvadratsumman fortfarande a² + b². Punkterna ligger alltså lika långt från origo. För z = 0 är argumentet inte definierat.

Skilj från konjugering

z̄ = a − bi

Konjugatet speglar punkten i realaxeln. Det är inte generellt samma operation som att multiplicera eller dividera med i. Kontrollera med både algebra och ett ritat talplan.

06 · Individuell utcheckning

Förklara båda rotationerna

4 minuter själv – visa mellanled

z = 1 − 2i

1. Beräkna iz och z/i och ange båda punkternas koordinater.

2. Vilken rotation är moturs och vilken är medurs?

3. Visa att de tre talen har samma absolutbelopp.

iz = i(1 − 2i) = i − 2i² = 2 + i

z/i = −i(1 − 2i) = −i + 2i² = −2 − i

|z| = √(1² + (−2)²) = √5

|iz| = √(2² + 1²) = √5

|z/i| = √((−2)² + (−1)²) = √5

Multiplikationen roterar 90° moturs; divisionen 90° medurs. Det är samma längd, bara olika riktningar.

Dagens mål

Jag kan beräkna och rita både iz och z/i, förklara varför rotationerna går åt olika håll och visa att absolutbeloppet bevaras.
