05 · Kontroll

Återskapa täljaren

Kvot: 2x² − x − 3

Rest: 12

Förutsäg och skrivVilken multiplikation kontrollerar divisionen? Varför är 12 en tillåten rest?

(x + 2)(2x² − x − 3) + 12

= 2x³ + 3x² − 5x + 6

Restens grad är 0, lägre än divisorns grad 1.

06 · Felanalys · par

Teckenfällan

−5x − (−2x) = −7x

Enskilt → par → klassVad har eleven gjort rätt? Var uppstår felet? Skriv den rättade raden och förklara.

−5x − (−2x) = −5x + 2x = −3x

Att subtrahera ett negativt uttryck innebär att addera motsvarande positiva uttryck.

07 · Vi gör · mindre stöd

Nu tar ni över

(x³ + 2x² − 5x − 6) ÷ (x + 3)

Enskilt → parSkriv uppställningen. Bestäm första kvottermen och genomför minst två subtraktioner. Du skriver – jag visar vid behov.

x³ + 2x² − 5x − 6 = (x + 3)(x² − x − 2)

Kvot: x² − x − 2. Rest: 0.

Kontrollera särskilt att varje kvotterm multipliceras med både x och 3.

08 · Självständig tillämpning

Din tur – utan färdig uppställning

(x³ − 4x + 3) ÷ (x − 1)

Enskilt → parSkriv 0x² i uppställningen så att termerna hamnar rätt. Redovisa kvot, rest och kontroll.

x³ + 0x² − 4x + 3 = (x − 1)(x² + x − 3)

Kvot: x² + x − 3. Rest: 0.

4.4 Polynomekvationer · Polynomdivision

Välj uppgifter från minst tre olika nivåer (1–5) i läromedlet.

Om du fastnar: Markera vilken högsta term du försöker få bort. Välj → multiplicera → subtrahera → upprepa.

Om du kan metoden: Välj svårare divisioner och kontrollera kvot och rest genom multiplikation.

Det tidigare underlaget anger nivåer, men inga verifierade uppgiftsnummer.

10 · Exit ticket · individuellt

Kan du förklara metoden?

(x² + x − 6) ÷ (x + 3)

Utan ledtrådar1. Bestäm kvot och rest. 2. Varför väljer du den första termen? 3. Hur kontrollerar du svaret?

x² + x − 6 = (x + 3)(x − 2)

Kvot: x − 2. Rest: 0. Första termen x väljs eftersom x · x = x².

Bedöm din förståelse
11 · Framåtblick

Från division till faktorsatsen

P(x) = (x − a)Q(x) + R

FörutsägVad händer om x = a? Hur kan vi då avgöra om x − a är en faktor?

P(a) = R

Om P(a) = 0 är resten 0 och x − a en faktor.
