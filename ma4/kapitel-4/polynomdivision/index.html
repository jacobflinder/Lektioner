03 · Koppla till det kända

Vad betyder division?

17 = 5 · 3 + 2

P(x) = D(x) · Q(x) + R(x)

P: ursprungligt polynom · D: divisor · Q: kvot · R: rest.

Divisionen är färdig när R = 0 eller när restens grad är lägre än divisorns grad.

FörutsägVad kan resten vara om vi dividerar med x + 2?

04 · Modellering · förutsäg → visa → förklara

Liggande stolen – ett klick i taget

(2x³ + 3x² − 5x + 6) ÷ (x + 2)

Skriv ett eget förslag före visningen. Jämför i par vid första kvottermen, teckenbytet och beslutet att avsluta.

Varför fungerar metoden?

Vi väljer varje kvotterm så att produkten med divisorn får samma högsta term som det som återstår. När hela produkten subtraheras försvinner den termen.

Vi behåller sambandet P = D · Q + R medan kvoten byggs upp. Fortsätt så länge en ny polynomterm i kvoten kan eliminera högsta återstående termen. Avsluta när resten är noll eller har lägre grad än divisorn.

05 · Kontroll

Återskapa täljaren

Kvot

Q(x) = 2x² − x − 3

Rest

R(x) = 12

Förutsäg och skrivVilken multiplikation kontrollerar divisionen? Varför är 12 en tillåten rest?

(x + 2)(2x² − x − 3) + 12

= 2x³ − x² − 3x + 4x² − 2x − 6 + 12
= 2x³ + 3x² − 5x + 6

Restens grad är 0, lägre än divisorns grad 1.

Som divisionsuttryck:

(2x³ + 3x² − 5x + 6)/(x + 2)
= 2x² − x − 3 + 12/(x + 2),   x ≠ −2.

Polynomidentiteten P = DQ + R gäller för alla x. Bråkuttrycket kräver x ≠ −2 eftersom nämnaren inte får vara noll.

Pröva stoppvillkoret

Vid division med x + 2 återstår 3x + 1. Är vi klara? Vilken kvotterm kan ta bort 3x? Vad ändras om det återstår 12?

Vi kan fortsätta med kvottermen 3: (3x + 1) − 3(x + 2) = −5. En konstant rest som 12 eller −5 har lägre grad än x + 2, så då är divisionen färdig. Även resten 0 innebär att vi är klara.

06 · Felanalys · par

Teckenfällan

Här är ett konstruerat felsvar:

−5x − (−2x) = −7x

Enskilt → par → klassVilket tecken måste ändras när vi tar bort parentesen? Förklara felet, skriv den rättade raden och kontrollera resultatet.

−5x − (−2x) = −5x + 2x = −3x

Hela raden i divisionen:

(−x² − 5x + 6) − (−x² − 2x)
= −x² − 5x + 6 + x² + 2x
= −3x + 6.

Att subtrahera ett negativt uttryck innebär att addera motsvarande positiva uttryck.

07 · Vi gör · mindre stöd

Nu tar ni över

(x³ + 2x² − 5x − 6) ÷ (x + 3)

Komplettera → fortsätt självFörsta kvottermen är given. Skriv hela produkten och första subtraktionen på papper innan du visar dem. Bestäm sedan nästa kvotterm och försök slutföra divisionen utan fler klick. Öppna bara de steg du behöver.

x³ + 2x² − 5x − 6 = (x + 3)(x² − x − 2)

Kvot: x² − x − 2. Rest: 0.

Kontrollera särskilt att varje kvotterm multipliceras med både x och 3.

08 · Självständig tillämpning

Din tur – utan färdig uppställning

(x³ − 4x + 3) ÷ (x − 1)

Innan du börjarVilken koefficient har x²-termen? I vilken kolumn ska −4x stå? Skriv själv en uppställning med en kolumn per grad.

x³ − 4x + 3 = x³ + 0x² − 4x + 3.

Nollkoefficienten behåller platsen för x². Polynomet ändras inte och −4x hör till x-kolumnen.

Självständigt → jämför efteråtGenomför divisionen. Redovisa kvot, rest och kontroll innan du jämför med en kamrat.

x³ + 0x² − 4x + 3 = (x − 1)(x² + x − 3)

Kvot: x² + x − 3. Rest: 0.

11 · Exit ticket · individuellt

Kan du förklara metoden?

(x² + x − 5) ÷ (x + 3)

4 minuter individuellt, utan ledtrådar1. Bestäm kvot och rest. 2. Varför väljer du den första termen? 3. Förklara när divisionen är klar och kontrollera svaret.

x² + x − 5 = (x + 3)(x − 2) + 1

Kvot: x − 2. Rest: 1. Första termen x väljs eftersom x · x = x².

Vi avslutar eftersom restens grad 0 är lägre än divisorns grad 1. Multiplicera tillbaka och addera resten för att kontrollera.
