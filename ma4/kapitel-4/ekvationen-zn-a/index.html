02 · Aktivera de Moivre

Vad händer vid upphöjning?

z = r(cos(v) + i sin(v))

Skriv själv → par

Vad händer med absolutbeloppet och argumentet hos z³?

z³ = r³(cos(3v) + i sin(3v))

Absolutbeloppet blir r³ och argumentet blir 3v (modulo 2π).

03 · Två villkor · en ekvation

Bestäm längden och riktningen var för sig

z³ = 8i

z = r(cos(v) + i sin(v))

z³ = r³(cos(3v) + i sin(3v))

8i = 8(cos(π/2) + i sin(π/2))

Tänk innan du klickarBeräkna nästa steg själv och jämför med en kamrat.
Nästa fråga:
1 · Absolutbelopp

r³ = 8

r = ∛8

= 2

Eftersom r = |z| ≥ 0 måste samtliga rötter ligga på cirkeln |z| = 2.

2 · Argument – glöm inte hela varv

Eftersom ett helt varv är 2π kan samma riktning beskrivas av flera vinklar:

3v = π/2 + 2πk

k ∈ ℤ

Här är k ett heltal, som kan vara positivt, negativt eller noll. Vi kan alltså få samma resultat trots att vinkeln har ökat med ett eller flera hela varv.

Samma riktning upprepas efter varje helt varv. Därför behöver vi 2πk innan vi dividerar argumentet med 3.

3 · Argument för alla rötterna

3v = π/2 + 2πk

v = (π/2 + 2πk)/3

= (π/2)/3 + (2πk)/3

= π/6 + (2πk)/3

Vi delade hela högerledet med 3, alltså både π/2 och 2πk. Fortfarande gäller k ∈ ℤ.

Vinklarna för k=0,1,2 blir olika. Sedan måste vi undersöka om fler k-värden ger nya riktningar.

06 · Från polär till rektangulär form

Skriv alla tre rötter exakt

Tänk innan du klickarBeräkna nästa steg själv och jämför med en kamrat.
Nästa fråga:
1 · Första roten

r = 2

v₁ = π/6

cos(π/6) = √3/2

sin(π/6) = 1/2

z₁ = r(cos(v₁) + i sin(v₁))

= 2(√3/2 + i/2)

= √3 + i

2 · Andra roten

r = 2

v₂ = 5π/6

cos(5π/6) = −√3/2

sin(5π/6) = 1/2

z₂ = r(cos(v₂) + i sin(v₂))

= 2(−√3/2 + i/2)

= −√3 + i

3 · Tredje roten

r = 2

v₃ = 3π/2

cos(3π/2) = 0

sin(3π/2) = −1

z₃ = r(cos(v₃) + i sin(v₃))

= 2(0 − i)

= −2i

4 · Kontrollera

z₁ = √3 + i

z₂ = −√3 + i

z₃ = −2i

3v₁ = π/2

3v₂ = 5π/2 = π/2 + 2π

3v₃ = 9π/2 = π/2 + 4π

r³ = 2³ = 8

Alltså ger alla tre vid kubering samma längd 8 och riktning π/2, det vill säga 8i. Rotvinklarna skiljer sig med 2π/3, så rötterna är olika.

Varför finns exakt n rötter?

Om a = R(cos(θ) + i sin(θ)) med R > 0 gäller följande när n är ett positivt heltal:

rⁿ = R

Här är r det positiva tal vars n:te potens är R (den positiva n:te roten ur R).

nv = θ + 2πk

v = (θ + 2πk)/n

k = 0, 1, …, n − 1

Då fås exakt n olika riktningar: två närliggande vinklar skiljer sig med 2π/n (ett icke-noll vinkelsteg mindre än ett helt varv). När k ökar med n får vi samma riktning igen. Om a = 0 är däremot bara z = 0 en rot.

Här har vi n = 3, så rotvinklarna ligger 120° ifrån varandra.
