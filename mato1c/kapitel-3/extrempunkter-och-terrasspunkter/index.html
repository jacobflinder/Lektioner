01 · Start · enskilt → par

Vågrät tangent. Samma sorts punkt?

Alla tre har derivatan noll vid x = 0. Vilka grafer vänder? Vilken fortsätter åt samma håll?

A · f(x) = x²
B · g(x) = −x²
C · h(x) = x³
Ta ställning före klicketVilken är minimipunkt, maximipunkt respektive terrasspunkt? Förklara varför f′(0)=0 inte räcker för att skilja dem åt.

A: minimipunkt – grafen går från att sjunka till att stiga. B: maximipunkt – grafen går från att stiga till att sjunka. C: terrasspunkt – grafen fortsätter att stiga genom en horisontell tangent.

Samma lutning i själva punkten ger alltså inte samma punktkaraktär.

* I våra polynomexempel finns en terrasspunkt om grafen dessutom byter böjning. Samma tecken hos derivatan på båda sidor bevisar inte ensamt böjningsbyte för alla funktioner.

Lokalt maximum/minimum

Högsta/lägsta funktionsvärde i närheten.

En punkt har två koordinater

Punkten: (a, f(a))

Värdet är f(a) – inte f′(a).

Viktig skillnad: f′(a) = 0 betyder horisontell tangent. Det räcker inte för att avgöra punktens karaktär. En terrasspunkt har dessutom ett byte i grafens böjning – det undersöker vi närmare i nästa moment.

Utan graf eller stöd: Om f′(x)=2x−4, var växer respektive avtar f? Visa ett testvärde på var sida om x=2.

f′(1)=−2 och f′(3)=2. Därför avtar f för x<2 och växer för x>2. Vid x=2 är derivatan noll.

08 · Individuell utcheckning

Vad säger tecknen – och vad saknas?

Svara själv på papper. Motivera med grafens beteende.

1 f′ har tecknen + 0 − runt x = 2. Dessutom är f(2) = 5. Vilken punkt har grafen? Ange karaktär och koordinater.
2 g′ har tecknen − 0 − runt x = −1. Dessutom är g(−1) = 4. Vilken stationär punkt kan du ange säkert, och är den en extrempunkt? Räcker uppgifterna för att säkert kalla den en terrasspunkt?
3 En elev säger: ”f′(3) = 0, alltså är (3, 0) en minimipunkt.” Vilka två saker behöver eleven undersöka?

1: Maximipunkt (2, 5). Derivatan går från positiv till negativ.

2: Grafen fortsätter att avta, alltså finns ingen extrempunkt vid x = −1. Vi vet att den stationära punkten är (−1, 4). Om grafen också byter böjning är det en terrasspunkt, som i våra polynomexempel – men det följer inte säkert av enbart tecknen − 0 −.

3: Undersök först derivatans tecken på båda sidor om x = 3 för att avgöra om punkten är ett minimum. Beräkna sedan f(3) för att bestämma punktens y-koordinat; derivatans nollställe ger inte höjden.

Dagens mål

Du kan bestämma punkttyp genom derivatans tecken på båda sidor.

Du kan ange koordinaterna genom att beräkna funktionsvärdet i punkten.

Enbart rätt namn på punkttypen räcker inte – motiveringen är viktig.

09 · Sammanfattning och läxa

Typ först. Koordinater sedan.

f′(a)=0 visar att tangenten är horisontell.

Tecknet före och efter visar hur grafen förändras: + 0 − maximum, − 0 + minimum. + 0 + eller − 0 − ger ingen extrempunkt; i våra polynomexempel med böjningsbyte är det en terrasspunkt.

Koordinater: (a, f(a)) – inte (a, f′(a)).
