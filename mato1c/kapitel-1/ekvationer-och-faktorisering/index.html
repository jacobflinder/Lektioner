Ekvationer och faktorisering

Polynomekvationer · s. 20–23

Bryt ut den största gemensamma faktorn ur 6x2 + 18x. Vilken faktor är lätt att tappa? Skriv först själv och jämför i par.

Efter lektionen ska du kunna

  1. Skriva ett andragradspolynom i faktorform och behålla koefficienten framför parenteserna.
  2. Lösa en polynomekvation genom att faktorisera och använda nollproduktmetoden.
  3. Faktorisera två grupper av termer för att hitta en gemensam parentes.
Visa återkoppling
6x2 + 18x = 6x · x + 6x · 3 = 6x(x + 3).

Tre sätt att faktorisera

  • Bryt ut den största gemensamma faktorn.
  • Läs konjugatregeln eller en kvadreringsregel baklänges när uttrycket passar.
  • Har ett andragradspolynom nollställena x1 och x2 kan vi använda faktorformen nedan. k är koefficienten framför x2.
p(x) = k(x − x1)(x − x2)

För att hitta nollställena sätter vi polynomet lika med noll. När vi har formen x2 + px + q = 0 kan vi använda pq-formeln.

x=−p2±(p2)2−q

Bryt ut koefficienten och hitta nollställena

Skriv h(x) = 5x2 − 45x + 100 i faktorform. Bryt först ut koefficienten framför x2.

Visa lösningen
h(x) = 5(x2 − 9x + 20)
h(x) = 0 ger x2 − 9x + 20 = 0.
x = 9/2 ± √((9/2)2 − 20)
x = 9/2 ± √(81/4 − 80/4) = 9/2 ± 1/2
x1 = 9/2 + 1/2 = 5
x2 = 9/2 − 1/2 = 4
h(x) = 5(x − 5)(x − 4)

Behåll minustecknet i faktorformen

Faktorisera p(z) = 20 + 15z − 5z2. Vilken faktor bryter du ut för att få +z2 i parentesen?

Visa lösningen
p(z) = −5(−4 − 3z + z2) = −5(z2 − 3z − 4)
p(z) = 0 ger z2 − 3z − 4 = 0.
z = 3/2 ± √((3/2)2 + 4)
z = 3/2 ± √(9/4 + 16/4) = 3/2 ± 5/2
z1 = 3/2 + 5/2 = 4
z2 = 3/2 − 5/2 = −1
p(z) = −5(z − 4)(z − (−1)) = −5(z − 4)(z + 1)

Bryt ut och använd konjugatregeln

Faktorisera 3x2 − 147. Bryt ut den gemensamma faktorn innan du använder konjugatregeln baklänges.

Visa lösningen
3x2 − 147 = 3(x2 − 49)
= 3(x2 − 72)
= 3(x + 7)(x − 7)

Från faktorform till rötter

En produkt är noll precis när minst en faktor är noll. Det är nollproduktmetoden. En konstant faktor som är skild från noll ger ingen egen rot.

Bryt ut en hel parentes

Lös x2(x + 2) − 36(x + 2) = 0. Vilken faktor finns redan i båda termerna?

Visa lösningen
(x + 2)(x2 − 36) = 0
x + 2 = 0 ger x = −2.
x2 − 36 = 0 ger x2 = 36.
x = ±√36 = ±6
Rötterna i storleksordning är −6, −2 och 6.

Faktorisera grupper av termer

Lös (x3 − 5x2) − (3x − 15) = 0. Faktorisera grupperna var för sig och leta efter en gemensam parentes.

Visa lösningen
x2(x − 5) − 3(x − 5) = 0
(x − 5)(x2 − 3) = 0
(x − 5)(x + √3)(x − √3) = 0
x − 5 = 0 ger x = 5.
x + √3 = 0 ger x = −√3.
x − √3 = 0 ger x = √3.
Rötterna i storleksordning är −√3, √3 och 5.

Utcheckning

  1. Faktorisera p(x) = −2x2 + 8x + 10. Visa hur du hittar nollställena.
  2. Lös (2x3 − 8x2) − (8x − 32) = 0. Vilken gemensam parentes hittar du och vilka faktorer kan bli noll?
Visa återkoppling
p(x) = −2(x2 − 4x − 5).
p(x) = 0 ger x2 − 4x − 5 = 0.
x = 2 ± √(22 + 5) = 2 ± 3. Nollställena är 5 och −1.
p(x) = −2(x − 5)(x + 1)
2x2(x − 4) − 8(x − 4) = 0
(x − 4)(2x2 − 8) = 0
2(x − 4)(x + 2)(x − 2) = 0
x − 4 = 0, x + 2 = 0 eller x − 2 = 0. Rötterna är −2, 2 och 4.

Extra · Repetera potenser och faktorform

  1. Förenkla (5x + 5x)2. Jämför med kvadreringsregeln.
  2. Lös 3x5 = 96 och (x − 2)3 = 27.
  3. Skriv x2 − 10x + 24 i faktorform när nollställena är 4 och 6.
Visa återkoppling
(5x + 5x)2 = (2 · 5x)2 = 4 · 52x = 4 · 25x
Kvadreringsregeln ger 52x + 2 · 52x + 52x = 4 · 25x.
3x5 = 96 ger x5 = 32 och x = 321/5 = 2.
(x − 2)3 = 27 ger x − 2 = 271/3 = 3 och x = 5.
x2 − 10x + 24 = (x − 4)(x − 6)
