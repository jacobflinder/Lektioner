Kärnväg: start/grundmetod 1–2; förutsäg med fast graf och följ en flyttad ändpunkt 3–4 (kort demonstration, inte en fristående räknestuga); genomarbetat exempel 3156 stegvis 5; självständig tillämpning 6; minst 20 min sammanhängande bokarbete 7; individuell utcheckning och facit i två separata steg 8–9. 01 · Start · enskilt → par

Var finns det största värdet?

Ett slutet intervall betyder att båda ändpunkterna ingår.

g(x)=x²,   −1 ≤ x ≤ 2

Ta ställning innan facit visas:
  1. Bestäm största och minsta värde.
  2. Vid vilka x antas värdena?
  3. Räcker det att lösa g′(x)=0?
Skissa grafen och markera båda ändpunkterna.

g′(x)=2x=0 ⇒ x=0

g(−1) = 1

g(0) = 0

g(2) = 4

Minsta värdet är 0 vid x=0. Största värdet är 4 vid x=2.

Nej, det räcker inte med nollställen till derivatan. Den största höjden finns här vid intervallets högra ändpunkt.

02 · Mål och metod

Jämför alla möjliga kandidater

Efter lektionen ska du kunna bestämma största och minsta värde i ett slutet intervall med derivata – och ange var värdena antas.

1 · Hitta kandidater

Lös f′(x)=0 och behåll de stationära x-värden som ligger i intervallet.

2 · Ta med ändpunkterna

Beräkna funktionsvärdet både vid stationära punkter och vid båda ändpunkterna.

3 · Jämför höjder

Välj största och minsta funktionsvärde. Ange också vid vilka x de antas.

Lokalt extremum betyder störst eller minst jämfört med närliggande punkter. Största/minsta värdet i intervallet betyder störst eller minst jämfört med alla tillåtna x.

Snabbt beslut – välj kandidater utan att räkna deras värden.

f(x)=x³−4,5x²+5,   −2 ≤ x ≤ 5

f′(x)=3x(x−3)

Vilka fyra x-värden ska jämföras?

Stationära x-värden: 0 och 3. Ändpunkter: −2 och 5. Jämför därför f(−2), f(0), f(3) och f(5).

03 · Förutsäg · samma graf, större intervall

Först: −2 ≤ x ≤ 3
Ingår Utanför intervallet
Vi har redan beräknat:

05 · Genomarbetat exempel 3156 · s. 159

Jämför alla fyra funktionsvärden

f(x)=x³−4,5x²+5,   −2 ≤ x ≤ 5

Före varje steg: Lös eller förutsäg nästa matematiska beslut på papper. Det är funktionsvärdena som ska jämföras.
Nästa fråga:
1 · Derivera och faktorisera

f′(x)=3x²−9x=3x(x−3)

2 · Välj alla kandidater

f′(x)=0 ⇒ x=0 eller x=3

Ändpunkterna är −2 och 5. Hela listan: −2, 0, 3 och 5.

3 · Beräkna första paret

f(−2)=−8−4,5·4+5=−21

f(0)=0−0+5=5

4 · Beräkna andra paret

f(3)=27−40,5+5=−8,5

f(5)=125−112,5+5=17,5

5 · Jämför och svara
x−2035
f(x)−215−8,517,5

Största värdet är 17,5 vid x=5.

Minsta värdet är −21 vid x=−2.

Slutsats: Det lokala maximumet 5 vid x=0 är inte längre det största värdet på hela intervallet. Det är 17,5 vid x=5.
06 · Din tur · mindre stöd

Bestäm både värdet och var det antas

h(x)=−x²+4x,   0 ≤ x ≤ 5

Skriv en fullständig lösning utan steglista. Bestäm funktionens största och minsta värde på intervallet och ange var de antas. Motivera valet av alla kandidater och varför jämförelsen räcker.
  1. Bestäm stationära x-värden och lägg till intervallets ändpunkter.
  2. Beräkna funktionsvärdena vid alla kandidater.
  3. Ange största och minsta värde samt x-värdena där de antas.
Kontrollera när din lösning är färdig

Derivera h′(x)=−2x+4 och lös h′(x)=0. Glöm inte x=0 och x=5 när du jämför funktionsvärdena.

h′(x)=−2x+4=0 ⇒ x=2

Vi testar x=0, x=2 och x=5.

h(0) = 0

h(2) = −4 + 8 = 4

h(5)=−25+20=−5

Största värdet är 4 vid x=2.

Minsta värdet är −5 vid x=5.

Varför testar vi x=0 fast det inte blev något av svaren? Därför att vi måste undersöka båda ändpunkterna innan vi kan jämföra hela intervallet.

Jämför din lösning. Komplettera det första steg som saknas.
