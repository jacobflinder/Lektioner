02 · Aktivera de Moivre

Vad händer vid upphöjning?

z = r(cos v + i sin v)

Skriv själv → par

Vad händer med absolutbeloppet och argumentet hos z³?

z³ = r³(cos 3v + i sin 3v)

Absolutbeloppet blir r³ och argumentet blir 3v (modulo 2π).

03 · Två villkor · en ekvation

Bestäm längden och riktningen var för sig

z³ = 8i = 8(cos(π/2) + i sin(π/2))

Tänk innan du klickarBeräkna nästa steg själv och jämför med en kamrat.
Nästa fråga:
1 · Absolutbelopp

r³ = 8 ⇒ r = ∛8 = 2

Eftersom r = |z| ≥ 0 måste samtliga rötter ligga på cirkeln |z| = 2.

2 · Argument – glöm inte hela varv

8i = 8[cos(π/2 + 2πk) + i sin(π/2 + 2πk)]

3v = π/2 + 2πk,   k ∈ ℤ

Samma riktning upprepas efter varje helt varv. Därför behöver vi 2πk innan vi dividerar argumentet med 3.

3 · Argument för alla rötterna

v = (π/2 + 2πk)/3

= π/6 + 2πk/3,   k ∈ ℤ

Vinklarna för k=0,1,2 blir olika. Sedan måste vi undersöka om fler k-värden ger nya riktningar.

04 · Eget steg · beräkna argument

Varför får vi just tre olika rötter?

v = π/6 + (2πk)/3

Tänk innan du klickarBeräkna nästa steg själv och jämför med en kamrat.
Nästa fråga:
1 · Första vinkeln

k = 0 ⇒ v = π/6 = 30°

2 · Andra vinkeln

k = 1 ⇒ v = π/6 + 2π/3 = 5π/6 = 150°

3 · Tredje vinkeln

k = 2 ⇒ v = π/6 + 4π/3 = 3π/2 = 270°

4 · Varför stannar vi här?

k = 3 ⇒ v = π/6 + 2π = 13π/6

v(k + 3) = v(k) + 2π

Varje ökning av k med 3 ger samma riktning efter ett helt varv. Därför räcker exakt k = 0, 1, 2 för att hitta samtliga olika rötter.

05 · Klickbar talplansmodell

Rita nästa rot innan den visas

0 av 3 olika rötter visade

Före varje klick: skissa själv → diskutera i par

Markera den första roten på cirkeln. Var hamnar vinkeln π/6?

k = 0 ger v = π/6 = 30°

Alla rötter har absolutbelopp 2. Vinkelsteget är 2π/3 = 120°. De färgade pilarna och cirkeln har samma matematisk skala på båda axlarna.

När tre rötter syns: testa även k = 3. Är det en fjärde rot?

06 · Från polär till rektangulär form

Skriv alla tre rötter exakt

Tänk innan du klickarBeräkna nästa steg själv och jämför med en kamrat.
Nästa fråga:
1 · Första roten

z₁ = 2(cos(π/6) + i sin(π/6))

= 2(√3/2 + i/2) = √3 + i

2 · Andra roten

z₂ = 2(cos(5π/6) + i sin(5π/6))

= 2(−√3/2 + i/2) = −√3 + i

3 · Tredje roten

z₃ = 2(cos(3π/2) + i sin(3π/2))

= 2(0 − i) = −2i

4 · Kontrollera

z₁ = √3+i,   z₂ = −√3+i,   z₃ = −2i

Alla har absolutbelopp 2 och argument som ger π/2 efter upphöjning till 3. Totalt tre olika rötter.

Varför finns exakt n rötter?

För n ett positivt heltal och a ≠ 0 har zⁿ = a exakt n olika komplexa rötter. De har samma absolutbelopp och argument som skiljer sig med 2π/n. När k ökar med n upprepas riktningen.

Här har vi n = 3, så rotvinklarna ligger 120° ifrån varandra.

07 · Självständigt försök

Kan du hitta alla rötter utan stöd?

Enskilt → par

z² = −4

Bestäm samtliga rötter, markera dem i talplanet och förklara varför det finns exakt två olika rötter.

−4 = 4(cos π + i sin π)

r² = 4 ⇒ r = 2

2v = π + 2πk ⇒ v = π/2 + πk

k = 0 ⇒ z₁ = 2i

k = 1 ⇒ z₂ = −2i

(2i)² = (−2i)² = −4

Två olika punkter ligger på imaginära axeln, i motsatta riktningar. När k ökar med 2 upprepas den första riktningen.

Visa vad du kan

2. Ange absolutbeloppet för varje rot.

3. Varför finns exakt tre olika rötter?

4. Skriv gärna rötterna i rektangulär form.

−8 = 8(cos π + i sin π),   r = 2

v = π/3 + 2πk/3,   k = 0, 1, 2
