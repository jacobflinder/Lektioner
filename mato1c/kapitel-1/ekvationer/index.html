Polynomekvationer · s. 20–23

Skriv två tal vars kvadrat är 36. Skriv ett sätt att kontrollera dina svar och jämför i par.

Efter lektionen ska du kunna

  1. Förenkla en ekvation och se vilken grad den har.
  2. Lösa en andragradsekvation med kvadratrotsmetoden eller pq-formeln.
  3. Göra en substitution och kontrollera lösningarna i den ursprungliga ekvationen.
Visa återkoppling
62 = 36 och (−6)2 = 36. Ekvationen x2 = 36 har båda lösningarna.

Kvadratrotsmetoden

En polynomekvation kan skrivas p(x) = 0, där p(x) är ett polynom. När endast andragradstermen återstår med x kan vi lösa direkt. Om x2 = a och a > 0 gäller x = ±√a.

Lös 5x2 − 48 = 2x2. Samla först allt i vänster led.

Visa lösningen
5x2 − 48 − 2x2 = 0
3x2 − 48 = 0
3x2 = 48
x2 = 16
x = ±√16 = ±4

Multiplicera parenteserna först

Lös (z − 1)(z − 3) = (z − 4)(z − 5). Skriv fyra produkter i varje led. Vilken grad har ekvationen efter förenkling?

Visa lösningen
z2 − 3z − z + 3 = z2 − 5z − 4z + 20
z2 − 4z + 3 = z2 − 9z + 20
−4z + 9z = 20 − 3
5z = 17
z = 17/5 = 3,4
Termerna med z2 tar ut varandra. Den förenklade ekvationen är av första graden.

Gör koefficienten framför x² till 1

För x2 + px + q = 0 ger pq-formeln

x=−p2±(p2)2−q

Lös 16x2 − 24x + 9 = 0. Vilka värden har p och q efter att du dividerat båda leden med 16?

Visa lösningen
x2 − (3/2)x + 9/16 = 0
p = −3/2 och q = 9/16
x=34±(34)2−916
x=34±916−916=34±0
x1 = x2 = 3/4. Ekvationen har en dubbelrot.

Byt variabel och kontrollera

Vid en substitution ersätter vi ett uttryck med en ny variabel. Om t = √x så är x = t2. Kontrollera varje kandidat mot t = √x när du byter tillbaka, eftersom √x är icke-negativ.

Lös x + 2√x − 8 = 0. Sätt t = √x och lös i t före kontrollen.

Visa lösningen
t2 + 2t − 8 = 0
t = −1 ± √((−1)2 + 8) = −1 ± √9 = −1 ± 3
t1 = −1 + 3 = 2. Då är x = 22 = 4 och √4 = 2.
t2 = −1 − 3 = −4. Då skulle x = (−4)2 = 16, men √16 = 4 ≠ −4.
Kontroll av x = 4 ger 4 + 2 · 2 − 8 = 0. Ekvationen har bara lösningen x = 4.

När en produkt är noll

En produkt är noll precis när minst en faktor är noll. Det är nollproduktmetoden.

Lös (3x − 6)(x + 4) = 0. Skriv en ekvation för varje faktor.

Visa lösningen
3x − 6 = 0 ger 3x = 6 och x = 2.
x + 4 = 0 ger x = −4.

Substitution i en fjärdegradsekvation

Om samma uttryck återkommer kan en substitution ge en andragradsekvation. Här är x4 = (x2)2.

Sätt t = x2 i x4 − 20x2 + 64 = 0. Hur många värden på x får du?

Visa lösningen
t2 − 20t + 64 = 0
t = 10 ± √(102 − 64) = 10 ± √36 = 10 ± 6
t1 = 16 ger x2 = 16 och x = ±4.
t2 = 4 ger x2 = 4 och x = ±2.
Båda värdena på x2 uppfyller ekvationen i t. De fyra lösningarna är −4, −2, 2 och 4.

Utcheckning

  1. Vilken grad har ekvationen (x + 2)(x + 1) = x2 + 8 efter förenkling?
  2. Lös 2x2 + 8x − 10 = 0 med pq-formeln.
  3. Sätt t = √x i x + √x − 6 = 0. Kontrollera kandidaterna.
Visa återkoppling
x2 + x + 2x + 2 = x2 + 8 ger 3x = 6. Graden är 1.
x2 + 4x − 5 = 0
x = −2 ± √(22 + 5) = −2 ± 3. Rötterna är −5 och 1.
t2 + t − 6 = 0
t = −1/2 ± √(1/4 + 6) = −1/2 ± 5/2
t = 2 ger x = 4 och √4 = 2. Kontroll: 4 + 2 − 6 = 0.
t = −3 skulle ge x = 9, men √9 = 3 ≠ −3. Bara x = 4 är en lösning.

Extra · En hyra som ger störst intäkt

Vid hyran 2 000 kr hyrs 50 stugor ut. För varje höjning med 100 kr hyrs en stuga färre ut.

Låt x vara antalet hundralappar som hyran höjs med. Skriv intäkten som en produkt. Förenkla, bestäm nollställena och använd symmetrilinjen för att hitta den största intäkten.

Visa lösningen
I(x) = (50 − x)(2 000 + 100x), där 0 ≤ x ≤ 50.
I(x) = 100 000 + 5 000x − 2 000x − 100x2
I(x) = −100x2 + 3 000x + 100 000
Produktens faktorer ger nollställena 50 och −20. Det negativa nollstället ligger utanför modellens intervall.
Symmetrilinjen ligger vid x = (50 − 20)/2 = 15. Parabeln är nedåtvänd, så där är intäkten störst.
I(15) = 35 · 3 500 = 122 500 kr. Hyran är då 3 500 kr.
