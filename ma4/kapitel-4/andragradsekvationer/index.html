1 · Start och mål

Andragrads­ekvationer i komplexa tal

Vi använder pq-formeln och ansatsen z = a + bi, precis som i filmgenomgången. Vi skriver alla led och använder villkor som b > 0 från uppgiftens början.

Startfråga · tänk först enskilt, sedan i parNär ger en andragradsekvation konjugerade rötter? Fundera på betydelsen av reella respektive komplexa koefficienter.
Efter lektionen ska du kunna
  • Normalisera en andragradsekvation och lösa med pq-formeln, med alla mellanled.
  • Ansätta z = a + bi, skilja realdel från imaginärdel och pröva båda fallen.
  • Använda ett givet villkor som b > 0, kontrollera en rot och förklara konjugatregeln.
2 · Återkalla och normalisera

Vad kan vi redan?

3 minuter själv → 1 minut i par. Skriv mellanled och förklara minst ett steg.

  1. Beräkna (2i)².
  2. Lös z² + 4z + 8 = 0 och ange båda rötterna.
  3. Hur kan en rot kontrolleras genom insättning?
Extra om du blir klar: beräkna (1 − i)²

Jämför din beräkning efter återkopplingen.

(2i)² = −4,   (1 − i)² = −2i

z² + 4z + 8 = 0

p = 4, q = 8

z = −p/2 ± √((p/2)² − q)

z = −2 ± √(4 − 8)

z = −2 ± √(−4)

z = −2 ± 2i

En rot kontrolleras genom insättning i ursprungsekvationen, till exempel (−2 + 2i)² + 4(−2 + 2i) + 8 = 0. Rötterna är konjugerade eftersom ekvationen har reella koefficienter.

Repetera först: ekvationer av första graden

Två tidigare metoder behövs även när vi löser mer komplicerade ekvationer.

Isolera z och förläng med konjugatet

z = 10i + 3iz

Samla alla termer med z på samma sida.

z − 3iz = 10i

z(1 − 3i) = 10i

z = 10i/(1 − 3i)

= (10i(1 + 3i))/((1 − 3i)(1 + 3i))

= (10i + 30i²)/(1 − 9i²)

= (10i − 30)/(1 + 9)

= (10i − 30)/10

= i − 3

z = −3 + i

När konjugatet ingår: ansätt rektangulär form

z + 2z̄ = 9 + 4i

Vad får du om z = a + bi? Vad blir konjugatet?

z = a + bi

z̄ = a − bi

Här är a och b reella.

(a + bi) + 2(a − bi)

= 9 + 4i

a + bi + 2a − 2bi = 9 + 4i

3a − bi = 9 + 4i

Realdel

3a = 9

a = 3

Imaginärdel

−b = 4

b = −4

z = 3 − 4i

Kontroll genom insättning:

(3 − 4i) + 2(3 + 4i)

= 3 − 4i + 6 + 8i

= 9 + 4i

Före pq-formeln: gör koefficienten framför z² till 1

2z² − z + 1 = 0

Filmens första andragradsexempel: bestäm den rot som har positiv imaginärdel och ange dess imaginärdel med två decimaler.

Försök självVilket tal dividerar du hela ekvationen med innan du använder pq-formeln?

(2z² − z + 1)/2 = 0/2

z² − (1/2)z + 1/2 = 0

p = −1/2

q = 1/2

z = −p/2 ± √((p/2)² − q)

z = 1/4 ± √((−1/4)² − 1/2)

z = 1/4 ± √(1/16 − 8/16)

z = 1/4 ± √(−7/16)

z = 1/4 ± (√7/4)i

Välj plusfallet eftersom uppgiften kräver b > 0:

b = √7/4 ≈ 0,66

3 · Filmmetod · pq-formeln

Komplex koefficient – samma pq-formel

z² − 2iz + 3 = 0

Vi söker först båda rötterna. I nästa steg bestämmer vi den som uppfyller z = a + bi, b > 0.

Förutsäg före lösningenHär är p = −2i och q = 3. Vad är (p/2)² − q? Varför kan vi inte förutsätta konjugerade rötter när koefficienten −2i inte är reell?
Varför fungerar pq-formeln även med komplexa koefficienter?

Kvadratkompletteringen använder samma räkneregler:

z² + pz + q = 0
⇔ (z + p/2)² = (p/2)² − q.

p = −2i, q = 3

z = −p/2 ± √((p/2)² − q)

z = −(−2i)/2 ± √(((−2i)/2)² − 3)

z = i ± √(i² − 3)

z = i ± √(−1 − 3)

z = i ± √(−4)

z = i ± 2i

z₁ = 3i, z₂ = −i

Av dessa har endast z₁ positiv imaginärdel: b = 3. Nästa bild löser exakt samma uppgift med ansatsen från filmen.

4 · Filmmetod · ansats

Ansätt z = a + bi och jämför delarna

Filmens uppgift och villkor från början

z² − 2iz + 3 = 0

z = a + bi,   a,b ∈ ℝ,   b > 0

Bestäm b. Vi känner ännu inte a och b, så vi sätter in ansatsen och skiljer på reell och imaginär del.

1 · Utveckla varje produktUtför kvadreringen och multiplikationen med −2i. Skriv hela vänsterledet.

(a + bi)² − 2i(a + bi) + 3 = 0

(a + bi)² = a² + 2abi + b²i²

= a² − b² + 2abi

−2i(a + bi) = −2ai − 2bi²

= −2ai + 2b

(a² − b² + 2b + 3) + (2ab − 2a)i = 0

2 · Realdel och imaginärdel blir nollSkriv båda ekvationerna. Faktorisera uttrycket som innehåller a och b.
Realdel

a² − b² + 2b + 3 = 0

Imaginärdel

2ab − 2a = 0

2a(b − 1) = 0

a = 0 eller b = 1

Pröva båda fallen i realdelens ekvation. Glöm inte villkoren a,b reella och b > 0.

3 · Pröva båda fallenVilka värden på b är möjliga? Varför måste ett av fallen förkastas?
Fall 1: a = 0

−b² + 2b + 3 = 0

b² − 2b − 3 = 0

b = 1 ± √(1 + 3)

b = 1 ± 2

b₁ = 3,   b₂ = −1

Vi kräver b > 0, därför förkastas b = −1.

Fall 2: b = 1

a² − 1 + 2 + 3 = 0

a² + 4 = 0

a² = −4

Omöjligt eftersom a ∈ ℝ.

4 · Svara och kontrolleraVilken av pq-formelns rötter uppfyller villkoret? Kontrollera i ursprungsekvationen.

a = 0, b = 3 ⇒ z = 3i

(3i)² − 2i(3i) + 3

= 9i² − 6i² + 3

= −9 + 6 + 3 = 0

Pq-formeln gav även z = −i, men den roten har b = −1 och uppfyller inte kravet b > 0.

Pröva själv utan lika många ledtrådar

Lös z² − 4iz + 5 = 0 med pq-formeln. Bestäm båda rötterna och markera vilken som har b > 0.

Skriv två rötter separerade med semikolon, till exempel 2i;-i.

Kontroll genom rötternas summa och produkt

Filmen kopplar pq-formeln till faktorformen. För z² + pz + q = 0 gäller:

(z − z₁)(z − z₂) = z² − (z₁ + z₂)z + z₁z₂

z₁ + z₂ = −p,   z₁z₂ = q

Kontrollera filmens rötter

z₁ = 3i, z₂ = −i

z₁ + z₂ = 3i − i = 2i = −p

z₁z₂ = (3i)(−i) = −3i² = 3 = q

(z − 3i)(z + i) = z² + iz − 3iz − 3i²

= z² − 2iz + 3

5 · Begrepp

Konjugerade eller motsatta?

Konjugat

a + bi ↔ a − bi

Spegling i realaxeln.

Motsatta tal

a + bi ↔ −a − bi

Spegling i origo.

Konjugat · realdelen bevaras

Blå punkt och röd punkt har samma realdel.

Motsatt tal · båda tecknen byts

Blå och grön punkt ligger mitt emot varandra genom origo.

6 · Metodval · elevaktivitet

Välj metod – och motivera

2 minuter själv → 2 minuter i par

Välj ett lämpligt första steg för A–D och motivera. Du behöver inte lösa alla. Lös sedan B själv och kontrollera minst en rot genom insättning.

UppgiftEkvationDitt beslut på papper
Az² − 9 = 0Vilken struktur ser du?
Bz² + 6z + 13 = 0Välj och genomför metoden.
Cz² − 4iz + 5 = 0Vilken pq-beräkning gör du?
D(z − 1)² = −4Vad är redan gjort?

A: z² = 9 ger direkt z = ±3. Faktorisering (z − 3)(z + 3) = 0 fungerar också.

B: pq-formeln, med p = 6 och q = 13.

z = −3 ± √(9 − 13) = −3 ± 2i
(−3 + 2i)² + 6(−3 + 2i) + 13
= 5 − 12i − 18 + 12i + 13 = 0

C: Sätt p = −4i, q = 5 i pq-formeln. Då fås z = 2i ± 3i, alltså 5i och −i. Samma resultat kan kontrolleras med ansatsen z = a + bi.

D: Formen är redan kvadratkompletterad: z − 1 = ±2i, alltså z = 1 ± 2i.

Flera metoder kan vara riktiga. Motivera vad i ekvationen som gör din metod lämplig.

7 · Begreppskontroll

När kommer konjugatpar?

För ekvationer med reella koefficienter hör icke-reella rötter ihop som konjugatpar. Med komplexa koefficienter finns inget sådant krav.

Välj och motiveraEkvationen z² + 4z + 13 = 0 har roten −2 + 3i. Vilken andra rot följer av koefficienterna?

Jämför med filmens komplexa koefficient

z² − 2iz + 3 = 0

Varför är rötterna 3i och −i inte konjugerade, trots att ekvationen är av andra graden?

Koefficienten framför z är −2i och är inte reell. Konjugatregeln kräver reella koefficienter.

z² + 4z + 13 = 0

z = −2 ± √(4 − 13) = −2 ± 3i

z² − 2iz + 3 = 0

z = i ± √(−1 − 3) = i ± 2i

z = 3i eller z = −i

Konjugatet till 3i är −3i, vilket inte är ekvationens andra rot.

Behöver du hjälp? Öppna filmens metodöversikt

1 · Normalisera först

Om koefficienten framför z² inte är 1, dividera hela ekvationen med den.

2z² − z + 1 = 0 ⇒ z² − (1/2)z + 1/2 = 0

2 · Pq-formeln

Skriv p och q, räkna uttrycket under roten och använd båda tecknen om inget villkor väljer en rot.

z = −p/2 ± √((p/2)² − q)

3 · Ansats när real- och imaginärdel ska bestämmas

Sätt z = a + bi med a,b reella. Utveckla och jämför realdel respektive imaginärdel. Faktorisera, pröva varje fall och använd villkoret b > 0 där det står i uppgiften.

4 · Kontroll och konjugatregeln

Sätt in roten i ursprungsekvationen. I polynom med reella koefficienter kommer icke-reella rötter parvis som konjugat; med komplexa koefficienter gäller det inte generellt.

10 · Individuell utcheckning

Visa filmens två metoder

6–7 minuter individuellt, utan facit. Skriv sammanhängande mellanled och kontrollera minst en rot.

  1. A · komplex koefficient, pq-formeln

    z² − 2iz + 8 = 0

    Bestäm båda rötterna. Redovisa p, q och stegen under rottecknet.
  2. B · normalisera och använd b > 0

    2z² − 2z + 5 = 0

    Bestäm den rot z = a + bi vars imaginärdel är positiv. Ange a och b.
  3. C · förklaraVarför är rötterna i B konjugerade, men inte nödvändigtvis rötterna i A?
Återkoppling – öppna efter eget försök

p = −2i, q = 8

z = −p/2 ± √((p/2)² − q)

z = i ± √(i² − 8)

= i ± √(−1 − 8)

= i ± 3i

z₁ = 4i, z₂ = −2i

(4i)² − 2i(4i) + 8 = −16 + 8 + 8 = 0

(2z² − 2z + 5)/2 = 0/2

z² − z + 5/2 = 0

p = −1, q = 5/2

z = 1/2 ± √(1/4 − 5/2)

z = 1/2 ± √(1/4 − 10/4)

z = 1/2 ± √(−9/4)

z = 1/2 ± (3/2)i

b > 0 ⇒ a = 1/2, b = 3/2

z = 1/2 + (3/2)i

I B är alla koefficienterna reella, så de två icke-reella rötterna är konjugerade: 1/2 ± (3/2)i. I A är koefficienten −2i inte reell, och därför gäller inte något krav på konjugerade rötter. Rötterna 4i och −2i är inte konjugat.
